# Лендинг «ЕГЭ / Физика» — Никита Лукашов

Минималистичный одностраничный сайт для преподавателя по подготовке к ЕГЭ по физике.

## Что заменить перед публикацией

- Telegram: в `index.html` найдите `href="https://t.me/"` и поставьте личную ссылку, например `https://t.me/your_username`.
- Имя преподавателя: можно добавить в `<title>` и в первый экран, когда оно будет известно.
- Цифры в блоке результатов при необходимости замените на реальные достижения.

## Запуск локально

Из папки проекта:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.
